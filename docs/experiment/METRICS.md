# Experiment Metrics

## Purpose

This document defines the metrics used to describe protocol execution and observed outcomes.

Metrics must not be used to manufacture causal conclusions.

## Experiment duration

- 108 days
- Day 1: 7 September 2026
- Day 108: 23 December 2026

## Protocol adherence

There are 13 daily protocol conditions.

### Successful-day definitions

The scoring definition is versioned:

- Days 1–46: Definition v1 — 13/13 required.
- Days 47–108: current threshold — at least 8/13 required.

Days 1–46 must never be retroactively recalculated under a later threshold.

Successful-day status is distinct from:

- productivity;
- financial success;
- health outcome;
- overall life success.

## 3-6-9 activity count

- 18 planned actions/day.
- 1,944 planned actions across 108 days.

The 3-6-9 count is an activity structure, not itself a causal outcome measure.

## Weight

Recorded weight may be used to describe the observed weight trajectory.

- Starting weight: 87.7 kg
- Target weight: 75 kg

Missing weight observations must remain missing and must not be converted to zero.

## Financial outcome

The primary financial target is:

- ₹3,00,000/month

Goal statement:

> I create 3 lakh per month through focused, valuable work that I consistently execute.

Financial observations should be recorded separately from protocol adherence.

## Hypothesis-related evidence

Relevant observations may include:

- protocol adherence;
- work execution;
- financial outcomes;
- health/fitness observations;
- focus/behavior observations;
- opportunity recognition;
- other pre-defined or explicitly exploratory observations.

These are evidence inputs. Their presence does not establish causation.

## Missingness

Every metric must preserve the distinction between:

- observed value;
- explicitly recorded zero;
- missing/unrecorded value;
- corrected value.

Analytics must account for missingness rather than treating it as zero.

## Metric changes

Changing a metric definition requires documentation and, where it changes experiment interpretation or historical scoring, the experiment amendment process.
