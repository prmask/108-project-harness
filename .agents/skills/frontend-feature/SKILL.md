# Frontend Feature

## Purpose
Implement approved UI/UX designs as maintainable, accessible frontend behavior.

## Procedure
1. Read product requirements and approved UX/UI design.
2. Identify existing components and patterns to reuse.
3. Confirm data and domain interfaces before building UI.
4. Implement the smallest coherent feature.
5. Implement all required interaction states.
6. Preserve accessibility and keyboard behavior.
7. Implement responsive behavior.
8. Connect to domain/application logic without embedding business rules in presentation components.
9. Add component/unit/integration tests as appropriate.
10. Perform visual and interaction verification.

## Rules
- Do not silently redesign approved UX.
- Do not put experiment scoring logic directly in React components.
- Do not introduce dependencies without justification.
- Do not hide missing or unfavorable data.

## Output
Implemented feature, states covered, tests, responsive/accessibility checks, and any deviations requiring approval.
