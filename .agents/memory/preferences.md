# Project Preferences

## Purpose
Non-authoritative development preferences that improve consistency.

## Current Preferences
- Prefer simple architecture over unnecessary infrastructure.
- Prefer local-first operation.
- Prefer small, coherent changes.
- Prefer evidence over gamified presentation.
- Prefer low-friction daily logging.
- Prefer reusable UI components.
- Prefer accessible and responsive interfaces.
- Prefer explicit uncertainty over false precision.
- Prefer primary sources for research.
- Prefer tests for important deterministic behavior.

## Authority
Preferences do not override requirements, experiment specifications, architecture decisions, security rules, or user instructions.
