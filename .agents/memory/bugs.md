# Bug Memory

## Purpose
Track recurring or important bugs and their lessons.

## Rules
- Not a substitute for issues or tests.
- Reproducible bugs should receive regression tests when practical.
- Do not store secrets or unnecessary sensitive data.
- Resolved bugs remain useful as historical lessons.
