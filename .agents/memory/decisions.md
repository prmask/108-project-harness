# Decision Memory

## Purpose
Lightweight memory of decisions that may still be relevant.

This is NOT the authoritative decision record.

## Rules
- Important architectural, product, experiment, and approved design decisions belong in `docs/decisions/`.
- Do not treat this file as an ADR.
- Record date, context, decision, reason, status, and authoritative reference.
- Mark superseded decisions rather than silently deleting history.
