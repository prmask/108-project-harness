# Architecture Memory

## Purpose
Non-authoritative working context about the application's technical architecture.

## Current Context
The project is intended to remain local-first and simple. Technical decisions must be verified against `docs/architecture/` and ADRs before implementation.

The application concerns protocol execution/scoring, health, mind, work, wealth, 3-6-9 practice, opportunities, journal entries, analytics, and experiment evidence.

## UI/UX Context
- Optimize for low-friction daily logging.
- Prefer reusable components and consistent interaction patterns.
- Support responsive and accessible interfaces.
- Keep missing data distinguishable from zero.
- Experiment-facing charts must not imply unsupported causation.
- Approved UX/UI decisions must be checked against current product/design documentation.

## Authority
This file is memory, not an architecture specification. Important architecture decisions belong in `docs/architecture/` or `docs/decisions/`.
