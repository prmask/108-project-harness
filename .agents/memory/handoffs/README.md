# Agent Handoffs

Use this directory for temporary context passed between agents or work sessions.

## Include
- task
- current status
- files changed
- decisions
- tests run
- known failures
- unresolved questions
- next action

## Rules
Handoffs are not authoritative. Verify important claims. Do not store secrets. Do not use handoffs as a substitute for project documentation.

