# Data Analysis

## Purpose
Analyze experiment data without overstating what the observations establish.

## Procedure
1. Define the analytical question.
2. Identify the relevant data and time period.
3. Validate completeness and missingness.
4. Preserve raw observations.
5. Calculate reproducible descriptive metrics.
6. Examine trends and relevant relationships.
7. Consider possible mechanisms.
8. Identify alternative explanations and confounders.
9. Report uncertainty and limitations.
10. Classify evidence against the relevant hypothesis.

## Analytical Chain
Measurement -> Trend -> Relationship/Correlation -> Possible Mechanism -> Hypothesis Assessment

## Rules
- Never fabricate or infer missing measurements.
- Never equate correlation with causation.
- Never selectively report favorable periods.
- Distinguish estimates from actual financial results.
- Distinguish protocol success from productivity and financial outcomes.
- Preserve negative, neutral, and challenging evidence.

## Output
Question, data used, validation, calculations, findings, uncertainty, alternative explanations, limitations, and hypothesis assessment.
