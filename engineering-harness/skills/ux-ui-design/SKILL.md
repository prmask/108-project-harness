# UX/UI Design

## Purpose
Design clear, low-friction, evidence-oriented interfaces for the 108-Day Experiment.

## Procedure
1. Read `AGENTS.md`, relevant product requirements, experiment specification, and hypotheses.
2. Define the user goal and context.
3. Map the information architecture and user flow.
4. Design wireframes before high-fidelity work when complexity warrants it.
5. Define reusable components, design tokens, variants, and interaction states.
6. Design normal, loading, empty, missing-data, error, success, correction, and historical states.
7. Design responsive behavior for desktop, tablet, and mobile.
8. Check accessibility and keyboard usability.
9. Check that visualizations distinguish observation, interpretation, correlation, and causation.
10. Prepare implementation-ready handoff.
11. Review implementation against the approved design.

## Project Rules
- Optimize for fast daily logging and clear evidence.
- Missing data must never visually imply zero.
- Do not use gamification to obscure experiment results.
- Do not visually imply causal conclusions that data cannot support.
- Clearly distinguish protocol success from productivity and financial success.
- Preserve historical scoring visibility.
- Prefer calm information density over decorative complexity.

## Figma
When Figma is used, create reusable components, variants, tokens, key states, and implementation notes. Follow the project's Figma workflow requirements before using Figma tools.

## Output
User flow, information architecture, wireframes/high-fidelity designs as appropriate, component/state specification, responsive/accessibility notes, and implementation handoff.
